# OIDC and RBAC Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Enforce OIDC authentication, organization-scoped RBAC, trusted risk
approval identity, and authenticated console access for the M1 technical
preview.

**Architecture:** Add a FastAPI authentication boundary that validates JWTs
through OIDC discovery/JWKS and maps claims into an immutable principal. Route
dependencies enforce organization and capability checks before existing domain
services run; domain services receive trusted actor context. The Vue console
uses authorization-code flow with PKCE and renders capabilities from the
authenticated session.

**Tech Stack:** Python 3.12, FastAPI dependencies, Pydantic settings, PyJWT with
cryptography, SQLAlchemy/Alembic, pytest, Vue 3, Pinia, TypeScript,
`oidc-client-ts`, Vitest, and Playwright.

**Design reference:** `docs/security/oidc-rbac-design.md`.
